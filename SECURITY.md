# Reporting a security issue

Please [report a vulnerability privately on GitHub](https://github.com/felixleopold/notecolab/security/advisories/new).
You can also contact [Felix Mrak](mailto:contact@felixmrak.com) directly.
Do not post private note content, complete share links, credentials, or an
exploitable vulnerability in a public issue.

Include the affected version, a minimal reproduction using disposable notes,
the expected and observed behavior, and the impact. Reports about the plugin,
API, web client, and deployment templates are all relevant.

See [the security model](SECURITY-CONSIDERATIONS.md) for the distinction between
client-encrypted stored content and relay-visible live collaboration. Open source
does not imply an independent security audit. We do not claim one.
